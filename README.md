# Am I Still Me?

A haunted mirror that replaces your face piece by piece, then makes you face the Ship of Theseus paradox.

Built for **Kiroween 2026** (Costume Contest) with [Kiro](https://kiro.dev), spec-first.

## Privacy
Your photo is processed **only in your browser**. It is never uploaded, stored or logged.

## How I used Kiro
- Specs: `.kiro/specs/am-i-still-me/` (requirements, design, tasks)
- Steering: `.kiro/steering/` (product, tech, structure, design system, motion, QA)
- Property-based tests and agent hooks: see the spec
